## Store Listing

**Extension Name**
ИНН / СНИЛС генератор

**Short Description**
ИНН, СНИЛС, ОГРН, БИК, банковские реквизиты, ФИО и адреса с валидными контрольными числами. По желанию — автозаполнение форм.

**Detailed Description**
Генератор валидных тестовых реквизитов для тестирования форм, вёрстки и демонстраций. Все номера выглядят настоящими — проходят проверку по контрольным числам ФНС, ПФР и методике ЦБ, но не принадлежат реальным людям или организациям.

В popup выберите тип документа одним кликом: ИНН физического лица (12 цифр), ИНН индивидуального предпринимателя (12 цифр), ИНН юридического лица (10 цифр) или СНИЛС. Значение генерируется мгновенно с корректным регионом и контрольной суммой. Нажмите «Копировать», чтобы вставить номер в любую форму. Горячие клавиши: R — сгенерировать новое значение, C — скопировать.

Автозаполнение форм: по умолчанию расширение не работает ни на одном сайте. Откройте нужный сайт, кликните на иконку расширения и нажмите «Добавить этот сайт» — Chrome спросит разрешение только для этого домена. После подтверждения сайт добавляется автоматически и расширение сразу начинает работать на открытой странице. Оно находит известные поля (по name, id, placeholder, подписи label и другим атрибутам) и показывает рядом кнопку «Заполнить»: банковские реквизиты (БИК, расчётный и корреспондентский счёт, ИНН/КПП и название банка), регистрационные номера (ОГРН, ОГРНИП, КПП, ОКПО, ОКТМО, ОКВЭД), ФИО и персональные данные (фамилия, имя, отчество, СНИЛС, паспорт, телефон, e-mail), адрес (индекс, регион, город, улица, дом, квартира). Значения на странице согласованы между собой: одна страница — одно лицо, одна организация, один банк, один адрес. Вставка совместима с современными фреймворками (React, Vue, Angular). Поля банковских карт не затрагиваются.

Расширение работает полностью офлайн. По умолчанию оно не имеет доступа ни к одному сайту и не собирает, не хранит и не передаёт ваши данные. Локально сохраняется только список сайтов, которые вы сами добавили. Тёмная тема включается автоматически по системным настройкам.

Предназначено только для тестирования. Не используйте сгенерированные номера в официальных документах.

## Permissions Justification

По умолчанию расширение **не имеет host-разрешений** и не работает ни на одном
сайте. Авто-определение включается пользователем вручную для конкретного сайта —
при этом Chrome запрашивает доступ только к этому домену.

| Permission | Type | Justification |
|------------|------|---------------|
| `storage` | permission | Хранит список сайтов, добавленных пользователем (host-паттерны). Других данных нет. |
| `scripting` | permission | Внедряет код авто-определения полей только на добавленных сайтах. |
| `activeTab` | permission | Чтение URL текущей вкладки в popup для отображения статуса сайта. |
| `http://*/*`, `https://*/*` | optional_host_permissions | Запрашиваются по клику пользователя для конкретного домена через «Добавить этот сайт». До добавления сайтов доступ к сайтам отсутствует. |

Копирование работает через Clipboard API без отдельного разрешения.

## Review Notes

### Known Issues / Limitations

- Сгенерированные значения — вымышленные. В описании явно указано, что расширение
  предназначено только для тестирования и не должно использоваться в официальных
  документах. Это снижает риск обвинений в содействии мошенничеству.
- Регион ИНН выбирается случайно из валидных кодов субъектов РФ.
- СНИЛС форматируется по стандарту `XXX-XXX-XXX YY`.
- Авто-определение полей работает только на сайтах, добавленных пользователем.
  Поддерживаются light DOM верхнего фрейма и same-origin iframe; Shadow DOM и
  cross-origin iframe с других доменов не поддерживаются.
- Пользовательские скрипты (кастомные поля): код вводится пользователем
  локально в диалоге настройки, сохраняется в chrome.storage.local и
  выполняется только на сайтах, добавленных этим пользователем. Никакого
  удалённого кода и загрузок из сети; скриптам недоступны API расширения —
  только контекст поля и генераторы значений.
- Сгенерированные банки, организации и адреса вымышлены: набор городов и улиц
  реален, но комбинации не соответствуют существующим контрагентам. ОКТМО точен
  для крупных городов, у остальных — правдоподобный формат.
- По умолчанию расширение не запрашивает host-разрешений и не обращается к сети —
  это упрощает ревью по приватности.
