# Chrome Web Store Listing — ИНН / СНИЛС генератор

> Last Updated: 2026-08-12

## Store Listing

**Extension Name**
ИНН / СНИЛС генератор

**Short Description**
Генерирует корректные ИНН (ФЛ, ИП, ЮЛ) и СНИЛС для тестирования. По желанию — находит поля ИНН/СНИЛС на выбранных сайтах и предлагает вставить значение одной кнопкой.

**Detailed Description**
Генератор валидных ИНН и СНИЛС для тестирования форм, вёрстки и демонстраций. Все номера выглядят настоящими — проходят проверку по контрольным числам ФНС и ПФР, но не принадлежат реальным людям или организациям.

Выберите тип документа одним кликом: ИНН физического лица (12 цифр), ИНН индивидуального предпринимателя (12 цифр), ИНН юридического лица (10 цифр) или СНИЛС. Значение генерируется мгновенно с корректным регионом и контрольной суммой. Нажмите «Копировать», чтобы вставить номер в любую форму. Горячие клавиши: R — сгенерировать новое значение, C — скопировать.

Авто-определение полей: по умолчанию расширение не работает ни на одном сайте. Откройте нужный сайт, кликните на иконку расширения и нажмите «Добавить этот сайт» — Chrome спросит разрешение только для этого домена. После этого на страницах сайта расширение само находит поля ИНН/СНИЛС (по name, id, placeholder, подписи label) и предлагает рядом аккуратную кнопку-иконку. При наведении она раскрывается в две кнопки — ФЛ (12 цифр) и ЮЛ (10 цифр); у поля СНИЛС — одна кнопка. Вставка совместима с современными фреймворками (React, Vue, Angular).

Расширение работает полностью офлайн. По умолчанию оно не имеет доступа ни к одному сайту и не собирает, не хранит и не передаёт ваши данные. Локально сохраняется только список сайтов, которые вы сами добавили. Тёмная тема включается автоматически по системным настройкам.

Предназначено только для тестирования. Не используйте сгенерированные номера в официальных документах.

**Category**
Developer Tools

Генерирует валидные тестовые номера ИНН и СНИЛС с правильными контрольными числами для использования при разработке и тестировании.

## Permissions Justification

По умолчанию расширение **не имеет host-разрешений** и не работает ни на одном
сайте. Авто-определение включается пользователем вручную для конкретного сайта —
при этом Chrome запрашивает доступ только к этому домену.

| Permission | Type | Justification |
|------------|------|---------------|
| `storage` | permission | Хранит список сайтов, добавленных пользователем (host-паттерны). Других данных нет. |
| `scripting` | permission | Внедряет код авто-определения полей только на добавленных сайтах. |
| `activeTab` | permission | Чтение URL текущей вкладки в popup для отображения статуса сайта. |
| `http://*/*`, `https://*/*` | optional_host_permissions | Запрашиваются по клику пользователя для конкретного домена через «Добавить этот сайт». До добавления сайтов доступ к сайтам отсутствует. |

Копирование работает через Clipboard API без отдельного разрешения.

## Review Notes

### Known Issues / Limitations

- Сгенерированные значения — вымышленные. В описании явно указано, что расширение
  предназначено только для тестирования и не должно использоваться в официальных
  документах. Это снижает риск обвинений в содействии мошенничеству.
- Регион ИНН выбирается случайно из валидных кодов субъектов РФ.
- СНИЛС форматируется по стандарту `XXX-XXX-XXX YY`.
- Авто-определение полей работает только на сайтах, добавленных пользователем, и
  только в light DOM верхнего фрейма (без Shadow DOM и cross-origin iframe).
- По умолчанию расширение не запрашивает host-разрешений и не обращается к сети —
  это упрощает ревью по приватности.
