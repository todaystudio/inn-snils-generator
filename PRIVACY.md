# Политика конфиденциальности — ИНН / СНИЛС генератор

Последнее обновление: 2026-08-12

## Какие данные мы собираем

**Никакие.** Расширение «ИНН / СНИЛС генератор» не собирает, не хранит и не
передаёт никакие персональные данные или информацию о посещаемых вами сайтах.

## Как работает расширение

Расширение генерирует случайные номера ИНН и СНИЛС с корректными контрольными
цифрами исключительно локально, на вашем устройстве.

Две части расширения:

1. **Генератор (popup).** Все вычисления происходят в окне расширения по запросу.
   Сгенерированные значения не сохраняются после закрытия окна расширения.
2. **Авто-определение полей на сайтах.** По умолчанию **отключено везде**. Чтобы
   включить его для конкретного сайта, вы сами нажимаете «Добавить этот сайт» и
   подтверждаете системный запрос Chrome на доступ **только к этому домену**.
   После этого расширение находит на страницах сайта поля ИНН/СНИЛС и предлагает
   рядом кнопку вставки сгенерированного значения. Содержимое полей и страниц
   **не считывается, не сохраняется и никуда не передаётся** — расширение лишь
   определяет тип поля по его атрибутам (`name`, `id`, `placeholder`, `aria-label`,
   тексту связанного `<label>`) и подставляет значение по вашему клику.

## Разрешения

- `storage` — хранит **только список сайтов, которые вы сами добавили**
  (host-паттерны вида `https://example.com/*`).
- `scripting`, `activeTab` — внедряют код авто-определения только на добавленных
  сайтах и читают URL текущей вкладки в окне расширения.
- `optional_host_permissions` (`http://*/*`, `https://*/*`) — позволяет запросить
  доступ к конкретному сайту **по вашему клику**. Никаких host-разрешений нет до
  тех пор, пока вы сами не добавите сайт.

По умолчанию расширение не имеет доступа ни к одному сайту.

## Хранение данных

Расширение использует `chrome.storage.local` исключительно для хранения списка
добавленных вами сайтов. История сгенерированных значений и содержимое полей
не сохраняются.

## Сторонние сервисы

Расширение не использует сторонние сервисы, не подключается к интернету и не
обращается к внешним API.

## Передача данных

Данные не передаются за пределы вашего устройства. Единственное действие с
сгенерированным значением — копирование в буфер обмена по вашему запросу или
вставка в поле по вашему клику.

## Файлы cookie и аналитика

Расширение не использует файлы cookie, средства аналитики и инструменты
отслеживания.

## Контактная информация

Если у вас есть вопросы о приватности, свяжитесь с разработчиком через форму
поддержки на странице расширения в Chrome Web Store.
