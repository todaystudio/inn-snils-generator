Стенд для проверки авто-определения

Откройте эту страницу по адресу http://localhost:8000/dev/test-page.html (запустите в папке проекта python3 -m http.server 8000), кликните на иконку расширения → «Добавить этот сайт». Рядом с каждым распознанным полем появляется кнопка «Заполнить»; у ИНН она раскрывается в ФЛ/ЮЛ. Значения согласованы: один банк, одна организация, одно лицо на страницу.

Базовые поля

name="inn" + <label>ИНН</label> — раскрывается в ФЛ/ЮЛ
комбинированное поле — вставит «ИНН/КПП» одной строкой
name="snils" + <label>СНИЛС</label>
name="tax_id", type=tel, placeholder «ИНН»
aria-label="СНИЛС …"

Банковские реквизиты

обычный ИНН юрлица, согласованный с БИК и к/с
20 цифр, контрольный ключ по БИК

Реквизиты организации

placeholder-шаблон https://___.__ → URL, согласованный с организацией

Персональные данные

type=email + autocomplete=email — домены example.com (RFC 2606)
maxlength=10 — вставится 10 цифр без +7

Адрес

согласован с городом
полный адрес одной строкой
textarea — авто-определение адреса

Не заполняется

не распознаётся — научите через «+»
карточные поля не трогаем
не распознаётся — можно научить через «+» (тип или скрипт)
тоже не распознаётся — кандидат на «+»
нераспознанное поле — кнопки быть не должно
